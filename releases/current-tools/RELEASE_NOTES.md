Build the Windows port from your own game copies, or import your own Xbox 360 XIII-2 saves.

Downloads:

- **Final-Fantasy-XIII-2-Builder.zip**: unzip and double-click **Build Final Fantasy XIII-2.bat**. Includes resumable setup, Mog-style prompts, optional PS3/Steam inputs, original Xbox DLC, and an EXE icon generated from your own game.
- **Final-Fantasy-XIII-2-Save-Importer.zip**: unzip, close the game, and double-click **Import Final Fantasy XIII-2 Save.bat**. Select the original Xbox save package and the builder output folder. Existing XIII-2 saves and headers are backed up before import. Final Fantasy XIII saves are rejected.
- **SHA256SUMS.txt**: checksums for both downloads.

Original Xbox DLC has worked in user testing with English and Japanese voices. Base-game Japanese lip-sync has worked in the tested gameplay. These reports do not establish complete scene or battle coverage.

**Steam DLC conversion remains experimental:** Omega crashes and Valhalla character texture problems remain unresolved. Japanese voices do not require installing converted Steam DLC. **Android is on hold.**

Local validation covers package checksums, PowerShell parsing, interrupted-build resume, content separation, save preservation, synthetic disc extraction, icon generation, and Xbox save extraction/header generation. The complete standalone Windows build, interactive save wrapper, and imported save's in-game loading still need Windows testing.

Source and tools only. Supply your own game files and saves; none are included in these downloads.
